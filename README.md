# HRM - Quản Lý Nhân Sự (Enterprise UI)

Hệ thống giao diện quản lý nhân sự doanh nghiệp hiện đại, trực quan và tối ưu trải nghiệm người dùng.

## 🚀 Công nghệ sử dụng

- **React 18**
- **Vite**
- **Lucide Icons**
- **Vanilla CSS (Design Tokens, Glassmorphism, Micro-interactions)**

## 🛠️ Cài đặt & Khởi chạy

1. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```

2. Khởi chạy môi trường phát triển:
   ```bash
   npm run dev
   ```

3. Đóng gói cho production:
   ```bash
   npm run build
   ```
